一、靶场说明

1.1 这是什么

一个故意写得不安全的迷你 Web 应用，专门用来练习 SQL 注入。代码里没有任何过滤、参数化查询或转义，所有输入都直接拼进 SQL 语句。

七、第 4 关：盲注

地址：http://127.0.0.1/lab/level4.php?id=1

7.1 什么是盲注

看不到回显，也看不到报错，只能通过页面行为的差异去推断数据：

  • 布尔盲注：构造真假条件，看页面”有/无”的差异，一位一位猜。
  • 时间盲注：构造 SLEEP()，看响应时间长短，适用于连”有/无”差异都没有的极端情况。

九、常见问题排查

Q1：sqlmap 说 “does not seem to be injectable”

按顺序检查：

  1. URL 写错了吗？先用浏览器能打开。
  2. 加 --level=3 --risk=2 加大测试强度。
  3. 加 --technique=BEUST 全技术测试。
  4. 如果是 POST，确认 --data 格式和浏览器一致。
  5. 加 --flush-session 清掉上次的错误缓存。
  6. 加 --random-agent 换个 UA（有些站点按 UA 拦工具）。

Q2：页面返回 500，但浏览器里正常

说明后端在异常时直接崩了。本靶场已修复此问题（mysqli_report(MYSQLI_REPORT_OFF)），如果你改坏了代码，检查 PHP 语法：

Q3：盲注扫得特别慢

  • 加 --threads=10
  • 只用 --technique=B
  • 缩小范围：-D 库 -T 表 --dump

Q4：--os-shell 一直失败

本靶场的数据库账号没有 FILE 权限，也做不到堆叠查询。要用 --os-shell，需要同时满足：

  1. 数据库账号有 FILE 权限；
  2. Web 目录对运行用户可写；
  3. secure_file_priv 允许写入目标目录。

用第 8.3 节的方法临时加权限即可练习。

十、学习路线

练完这个靶场，建议按顺序继续：

阶段 目标 说明
1 本靶场 4 关全手工通关 不依赖 sqlmap，先建立直觉
2 本靶场用 sqlmap 全自动通关 熟悉参数和输出
3 DVWA 有 Low/Medium/High 三档防护，练习绕过
4 sqli-labs（65 关） 覆盖几乎所有注入变形
5 PortSwigger Web Security Academy 免费在线靶场，有官方讲解，最推荐
6 HackTheBox / TryHackMe 综合渗透场景

手工注入必须掌握的三件事

  1. 判断注入点：' 看报错、AND 1=1/1=2 看差异
  2. 判断列数：ORDER BY 二分法
  3. 找回显位：UNION SELECT 1,2,3...

这三步是所有 UNION 注入的基础，sqlmap 内部也是这么做的。
